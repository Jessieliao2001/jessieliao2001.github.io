# Personal website

This repository contains the source for Jiaying (Jessie) Liao's personal
website. It is a dependency-free static site hosted with GitHub Pages.

## Project structure

- `index.html` — home page
- `about.html` — biography and research interests
- `research.html` — research areas
- `education.html` — education history
- `cv.html` — curriculum vitae placeholder
- `contact.html` — contact and profile links
- `style.css` — shared design tokens, layout, and responsive styles
- `CNAME` — custom domain configuration for GitHub Pages

## Local preview

Open `index.html` directly in a browser, or serve the directory with any static
file server. No installation or build step is required.

When adding a page, copy the shared header and footer from an existing page,
update the active navigation link, and keep page-specific styles grouped in
`style.css`.
